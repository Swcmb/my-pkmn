## 方法

1. 只统计日志里以 `「卡名」` 形式出现过的卡；一名多印刷按名称合并取最小 cardId。
2. 入选门槛 p ≥ 0.3，p = 「该卡在该队至少出现一次的局数」/ 观测局数。
3. 张数 n = clip(round(1 + 3p), 1, 4)；ACE SPEC 固定 1 张。
4. 总数不足 60 按 p 降序逐个加到 4；超出则从 p 最低端整种删除（保底 1 种基础宝可梦）。
5. 剩余名额按出现次数占比分给日志中出现过的基础能量（cardType=5，同名 ≤4 豁免）。

**已知偏差**：日志只记录「被用到/被提到」的卡。起手卡、没抽到的卡、以及一整局没产生效果的卡（例如某些竞技场/工具）会漏统计，因此 p 系统性偏低，牌组里的**卡种数偏少、单种张数偏高**。

## 置信度分级口径

| 级别 | 判据 | 含义 |
| :--- | :--- | :--- |
| 高 | p ≥ 0.80 | 几乎每局都出现，卡种判定基本可靠；张数仍可能因漏统计而偏高 |
| 中 | 0.50 ≤ p < 0.80 | 多数局出现，卡种判定较可靠，是否满 4 张不确定 |
| 低 | 0.30 ≤ p < 0.50 | 仅少数局出现，可能是关键单卡，也可能是对手/环境噪声 |
| 未列出 | p < 0.30 | 日志中出现但低于门槛，视为不可靠证据，未纳入 |
