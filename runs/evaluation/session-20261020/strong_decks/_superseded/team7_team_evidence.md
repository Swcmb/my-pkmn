# 还原牌组 · 食堂不要插队（team_id 7）

> **性质声明（§8.3）**：本牌组是从平台公开中文对局日志**推断**出来的，**不是**平台登记的官方 deck 列表。逐卡置信度必须一起读。

- 累计积分：3011（A 榜）
- 观测局数：44 局（该队被正确归属侧别的局数）
- 能量预算：10 张（由每局附能次数中位数得出），非能量卡预算 50 张
- 自检：60 张 / 16 种卡名 / ID 全部命中平台卡池 = True / 基础宝可梦 1 种 / ACE SPEC 合计 1 张 / 同名>4 无

## 方法

1. **侧别按行归属**：每条事件行自带 `A 方`/`B 方`，只统计归属本队的行；按 `▶` 块头继承会把对手的卡漏进来（实测污染，已修）。
2. **动作只数结算行**：同一个动作在日志里出现两次（`▶ A 方：打出「X」` 提示 + `A 方 打出「X」` 结算），只认后者，否则次数翻倍。
3. 卡名来自 `「…」`；一名多印刷按名称合并取最小 cardId。
4. 入选门槛 p ≥ 0.3，p = 该卡至少出现一次的局数 / 观测局数。
5. 初始张数 = `max(场面同局最大同时张数, 单局打出最大次数, 1)`，上限 4；ACE SPEC 固定 1。
6. 超出非能量预算 50 张则从 p 最低端整种删除（保底 1 种基础宝可梦）；不足则按 p 降序逐个 +1（上限 4）。
7. 能量预算 10 张 = 每局附能次数的中位数（clip 到 [6, 20]），按各能量卡的附能总次数占比摊派；基础能量（cardType=5）豁免同名 ≤4，特殊能量封顶 4。

## 局限

| 局限 | 影响 |
| :--- | :--- |
| 只统计日志中被提及的卡 | 起手卡、整局未用的卡会漏，卡种数偏少 |
| 场面解析只覆盖宝可梦 | 道具/支援者张数靠单局打出次数与 p，弱一档 |
| 假设该队在这些局里牌组不变 | 跨轮改牌组会把两套卡的证据混在一起 |
| 能量按附能占比摊派 | 能量之间几乎不可分辨，只保证总数 60 与类型合法 |
| 未与平台 deck 接口比对 | 平台不公开 deck 列表，无法证伪 |
