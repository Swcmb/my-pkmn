# 还原牌组 · 咪咪汪汪队（team_id 4）

> **性质声明（§8.3）**：本牌组是从平台公开中文对局日志**推断**出来的，**不是**平台登记的官方 deck 列表；能量张数部分是**先验**而非证据。逐卡置信度必须一起读。

- 累计积分：2774（A 榜）
- 观测局数：42 局
- 能量预算：10 张（每局附能 p75=5，×1.5 先验后 clip[10,20]）；非能量卡预算 50 张
- 自检：60 张 / 21 种卡名 / ID 全部命中平台卡池 = True / 基础宝可梦 3 种 / ACE SPEC 合计 1 张 / 同名>4 无
- 卡类型分布：{'宝可梦': 19, '道具': 15, '支援者': 13, '竞技场': 3, '基础能量': 5, '特殊能量': 5}

## 方法

1. **侧别按行归属**：每条事件行自带 `A 方`/`B 方`；按 `▶` 块头继承会把对手的卡漏进来（实测污染，已修）。
2. **动作只数结算行**：同一动作有 `▶ A 方：打出「X」` 与 `A 方 打出「X」` 两行，只认后者，否则次数翻倍。
3. **附能只认能量卡**：`将「C」附着到` 里 C 也可能是工具（Hop’s Choice Band、Hero’s Cape），必须按 cardType∈{5,6} 过滤。
4. 卡名来自 `「…」`；一名多印刷按名称合并取最小 cardId。
5. 入选门槛 p ≥ 0.3，p = 该卡至少出现一次的局数 / 观测局数。
6. 非能量初始张数 = `max(场面同局最大同时张数, 单局打出最大次数, 1)`，上限 4；ACE SPEC 固定 1。
7. 超出非能量预算 50 则从 p 最低端整种删除（保底 1 种基础宝可梦）；不足则按 p 降序逐个 +1（上限 4）。
8. 能量 10 张按附能总次数占比摊派：基础能量豁免同名 ≤4，特殊能量封顶 4，ACE SPEC 全局 ≤1。若日志中一种基础能量都没出现，则按牌组内宝可梦的 `energyType` 补对应基础能量。

## 局限

| 局限 | 影响 |
| :--- | :--- |
| 只统计日志中被提及的卡 | 起手卡、整局未用的卡会漏，卡种数偏少 |
| 场面解析只覆盖宝可梦 | 道具/支援者张数靠单局打出次数与 p，弱一档 |
| 假设该队在这些局里牌组不变 | 跨轮改牌组会把两套卡的证据混在一起 |
| **能量张数是先验不是证据** | p75 附能 ×1.5 只是经验系数，能量构成最不可靠 |
| 基础能量兜底靠属性推断 | 日志没出现的属性可能被补错 |
| 未与平台 deck 接口比对 | 平台不公开 deck 列表，无法证伪 |

## 置信度分级口径

| 级别 | 判据 | 含义 |
| :--- | :--- | :--- |
| 高 | p ≥ 0.80 | 几乎每局都出现，卡种判定可靠；张数仍可能因漏统计而偏低 |
| 中 | 0.50 ≤ p < 0.80 | 多数局出现，卡种判定较可靠，是否满 4 张不确定 |
| 低 | 0.3 ≤ p < 0.50 | 仅少数局出现，可能是关键单卡，也可能是回收/换牌噪声 |
| 未列出 | p < 0.3 | 出现但未过门槛，证据不足，未纳入 |
